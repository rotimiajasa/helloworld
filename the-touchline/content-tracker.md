# 🗂️ The Touchline — Content Tracker (how to run it)

`content-tracker.csv` is your command center. It's **pre-loaded with the June 8–17 plan**, so you can start immediately.

## Setup (2 min)
1. Open **Google Sheets → File → Import →** upload `content-tracker.csv` → *Insert new sheet*.
2. Freeze the top row (View → Freeze → 1 row).
3. Select the **Status** column → Data → Data validation → dropdown with the values below → turn on color.

## Columns
| Column | What goes in it |
|---|---|
| **Date / Day / UK Time** | When it publishes (UK time — your base) |
| **Pillar** | Brief · Breakdown · Reaction · Verdict · Live |
| **Format** | Short (9:16) · Long (16:9) · Live |
| **Title / Hook** | The actual hook/topic |
| **Platforms** | All, or specific (YouTube/TikTok/IG/X) |
| **Status** | Pipeline stage (below) |
| **Link** | Paste the published URL once live |
| **Notes** | Which script #, reminders |

## Status pipeline (color-code these)
`IDEA` → `SCRIPTED` → `FILMED` → `SCHEDULED` → `POSTED`
> 🟥 IDEA · 🟧 SCRIPTED · 🟨 FILMED · 🟦 SCHEDULED · 🟩 POSTED — aim to keep most rows at SCHEDULED ahead of each matchday.

## The daily loop (run this every matchday)
- [ ] **Morning:** post yesterday's "morning-after" recap + today's preview → mark `POSTED`, paste links.
- [ ] **Pre-kickoff:** queue today's preview/hot-take.
- [ ] **Within 60–90 min of full time:** instant reaction (template) → post → `POSTED`.
- [ ] **Evening:** batch tomorrow's evergreen → `SCHEDULED` in Buffer/Metricool.
- [ ] **First hour after each post:** reply to every comment (algorithm boost).
- [ ] **End of day:** add 2–3 new `IDEA` rows for upcoming fixtures.

## Weekly KPIs to log (add a tab)
Track these every Sunday so you know what's working:
`Followers (per platform) · Total views · Best post (views) · Best hook · Watch-time % · New email signups · Affiliate clicks/earnings`
> Double down on whatever format/hook had your biggest post that week.

## Blank row template (copy-paste into the sheet)
```
2026-06-__,,, Breakdown, Short, "HOOK HERE", All, IDEA, , 
```

## Rhythm to aim for during the tournament
- **2–4 short clips/day** (1 preview + 1–2 reactions + 1 evergreen)
- **1 long-form YouTube every 2–3 days**
- **1 TikTok LIVE** on marquee matchdays
- Never let a final whistle pass without a reaction within ~90 minutes.
