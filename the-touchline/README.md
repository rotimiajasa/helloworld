## 🚦 Setup checklist (do this before June 11)

### 1. Lock the handles (15 min)
Grab **@thetouchline** on TikTok, Instagram, X, and **@TheTouchline** on YouTube.
Check all at once at **namechk.com**. If taken, fall back to `@touchlineHQ` → `@watchtouchline` → `@touchline.fc` (use the **same** one everywhere).

### 2. Set every account's region to the **UK** (important for money)
Your UK base unlocks monetization programs Nigeria can't access. Register accounts with UK details from the start — don't switch later.

### 3. Set up the payment rail (UK earn → Nigeria settle)
- **YouTube/AdSense:** pays Nigeria directly — just link an AdSense account.
- **Everything else (TikTok, X, brand deals):** open a **multi-currency receiving account** — **Payoneer**, **Wise**, **Grey**, or **Geegpay** — to get **GBP/USD account details** these programs pay into, then settle to your Nigerian bank.
- **X ad-revenue** runs on **Stripe** (UK ✓, Nigeria ✗), so the Payoneer/UK route is what makes X payouts work.

### 4. Monetization-by-platform quick reference

| Platform | Threshold to unlock | Your status (UK base) |
|---|---|---|
| **YouTube long-form** | 1,000 subs + 4,000 watch-hrs/yr | ✅ Eligible (best ad money — focus here) |
| **YouTube Shorts** | 1,000 subs + 10M Shorts views/90d | ✅ Eligible (low RPM; use for reach) |
| **TikTok Creator Rewards** | 10k followers + 100k views/30d, videos **>1 min** | ✅ Eligible as **UK** (❌ would be blocked as Nigeria) |
| **TikTok LIVE gifts** | ~1k followers | ✅ Eligible — match watch-alongs (your voice only) |
| **Instagram** | Gifts/Subscriptions/branded content | ✅ Growth + brand-deal shop window |
| **X ads revenue** | Premium ($8/mo) + 500 verified followers + 5M impressions/3mo | ✅ via UK/Stripe route |

### 5. Income you can start on DAY ONE (no follower minimum)
- **Affiliate links** in every bio + pinned comment: **jerseys, football boots, streaming/VPN** (huge during a World Cup), gear. (Amazon Associates + retailer programs.)
- **A free lead magnet** — the "World Cup 2026 Predictions & Group Cheat-Sheet" PDF — to build an email list from day one.
- **TikTok LIVE gifts** during marquee matches.

### 6. ⚠️ The one rule that protects the whole business
**No match footage. No broadcast commentary. Ever.** FIFA auto-strikes it via Content ID and 3 strikes = channel deleted. Everything in this kit is built to be 100% defensible: your voice + stats + news + your own graphics. Add **"Not affiliated with FIFA"** to every bio.
